# 心网：需求与功能边界

更新日期：2026-10-27，版本 0.5.0。开发目录为 `C:\Users\24583\Desktop\hajiru`，用户选择仅免费托管，并要求女朋友通过专属链接免输账号密码进入。当前没有公网部署或手机实机认证结论。

## 1. 产品与视觉

保留用户参考的暗色星空、粉色粒子立体爱心、顶部音乐、标题、漂浮情话、姓名和实时计时，继续使用已确认的百合大小及楷体数字。英文装饰文案保持原样。新的账号与记录面板沿用原有视觉，支持电脑、手机、平板和横屏，较矮窗口可滚动。

原参考姓名与纪念时间来自用户文件；它们是展示设定，不是账户身份。初始数据库没有账号或假留言。测试记录只能存在于隔离数据库与独立浏览器环境。

## 2. 双人版功能

| 功能 | 当前实现 |
| --- | --- |
| 账号 | 用户自己设置登录名、昵称和密码；最多两个账号；首个账号从本机初始化或使用正式部署初始化密钥 |
| 会话 | HttpOnly Cookie；密码账号 14 天，免密码身份活跃使用续期、连续 90 天未用需恢复码；退出、改密码及恢复身份会撤销相应旧会话 |
| 专属入口 | 24 小时一次性邀请；女朋友无需注册或输入密码；后台建立独立身份，恢复码只存摘要且只向本人显示 |
| 绑定 | 登录者生成一次性邀请码；对方注册或已有账号接受；有效期 24 小时，重新生成使旧码失效 |
| 私密心里话 | 仅作者账号能从服务器读取、编辑、删除，不向伴侣返回正文、编号或数量 |
| 共享心里话 | 当前绑定双方可读，只有作者可改删，发布成功后才显示已进入共享空间 |
| 同步 | 前台约 5 秒轮询、聚焦/恢复联网/手动同步；没有虚构在线、已读或送达回执 |
| 并发 | 记录与共同设定使用版本号拒绝旧覆盖；新建使用幂等编号防重试重复 |
| 共同设定 | 姓名和纪念日由后端同步；音乐音量按设备保存 |
| 解绑 | 需当前密码；各自保留自己写的记录，对方不再能读；重绑不自动分享旧记录 |
| 备份 | 导出自己的已记录内容；旧文件先本地预览，确认后上传，全部作为私密导入，失败整体回退 |
| 维护 | 数据库持久保存、在线一致备份、排除私密数据的完整部署包 |

每个账号最多 500 条，每条最多 1,000 个 UTF-16 字符单位（与网页 maxlength 一致）；备份文件最大 2 MB。所有输入以纯文本显示。写操作失败保留原稿；服务器已提交但列表刷新失败时明确说明已保存。

## 3. 隐私权限

权限必须在后端逐条检查，不依赖页面隐藏、请求中的作者字段或浏览器分类。账号 A 无权读取 B 的私密内容；对方知道记录 ID 也得不到正文。共享内容仅在对应的有效绑定关系内读取，不能跨关系访问。

“仅本人可见”在本版指**普通账号之间的访问权限**。服务器维护者及有数据库权限的人仍可读取正文；未实现正文存储加密或端到端加密。HTTPS、数据库加密和端到端加密不能互相代称。

可使用独立密码账号或免密码设备身份，不共享同一份凭证。免密码恢复码每用一次会轮换并退出旧设备；对方不能查看或重置它。现阶段无邮件/短信找回；有权限维护数据库的人属于运维边界，不应宣称其无法访问。对方已看过或复制的共享内容无法通过撤回、改私密或解绑从对方设备上强制抹除。

## 4. 本地原型兼容与迁移

原本地心里话功能保留在 `npm run preview` 的原型模式：默认仅页面内存，明确勾选后写 localStorage，未加密、不按账号隔离。它与真实后端模式有独立标识。

双人版不自动读取、上传或删除旧 localStorage。后端状态无法确认时不降级到未隔离的旧记录界面。旧备份经当前用户预览并确认后上传，原来“想对你说”的内容也先转为仅本人可见。是否清理旧浏览器副本由用户决定。

退出/换账号立即清空页面记录、编辑草稿、导入预览和邀请码；同浏览器标签页通过会话变化通知同步清理，服务端仍独立校验每次请求。不得将上一账号的异步响应应用到下一账号。

## 5. 部署边界

前端采用原生网页模块；本机后端采用 Node.js 24 与 SQLite，云端采用 Netlify Free 同源入口 + Neon Free Functions/PostgreSQL，使用锁定版本的 pg 驱动。Render 因要求银行卡验证而停用。开发本机地址为 8790，同 Wi-Fi HTTP 测试入口为 8791；异地手机使用正式 HTTPS 网址。GitHub Pages 不能单独提供同步和私密权限。线上验收状态见验证记录。

正式模式要求精确 HTTPS 来源、可信回环代理、Secure Cookie、Host/Origin/CSRF 检查，不得用关闭检查或暴露未加密测试入口替代部署。数据库、真实 .env、账号会话和备份不进入公开文件或部署源包。实际部署后仍需验证证书、进程维护、备份恢复及 iOS/Android 实机。

## 6. 验收重点

- 两个独立会话真实注册、登录、绑定与持久记录，刷新和重启不丢数据。
- A/B 私密列表、详情及编辑/删除请求互相隔离；共享内容对双方可见而收件人不能修改。
- 越权作者字段、跨站请求、伪造 CSRF、无效/过期会话和邀请码不能改变数据。
- 解除关系立即撤销共享读取，重绑不重发旧记录；发送时关系变化拒绝误投到另一关系。
- 断网失败不假报成功；并发旧版本不覆盖；重复新建或导入不会产生重复条目。
- 换账号、过期和乱序返回不会保留或复活上一账号私密内容；导入预览同样清理。
- 旧功能仍可用，电脑与手机布局无横向溢出，原音乐与参考快照完整。
- 部署包不包含数据库、真实配置或备份；数据备份能读取最新提交内容且不覆盖已有文件。

实际通过数量和环境以 [验证记录](验证记录.md) 及浏览器结果 JSON 为准，不以本清单替代验证。
