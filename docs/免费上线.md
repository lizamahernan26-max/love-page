## 现在如何使用

1. 由你在电脑双击正式项目内的 data/心网首次开通.url，自行设置第一个账号和密码。钥匙会从地址栏移除；不要分享这个文件。已有本机账号和文字不会自动上传到云端。
2. 你在手机用正式网址登录自己的账号。点击“生成她的免登录邀请链接”，私下发送给她。
3. 她用常用手机浏览器打开邀请，点击“进入我们的心网”，无需用户名或密码。她独立保存自己的恢复码；以后同一浏览器自动识别。
4. “仅本人可见”只返回给作者；“两人共享”对绑定双方可见，只有作者能改删。两人都能这样使用。

邀请有效期 24 小时且只能使用一次。清除浏览器数据、换手机或退出后，她用恢复码进入；恢复码每次使用后更新，旧设备退出。你不能在自己账号取得她的恢复码。恢复码和 Cookie 都丢失时，目前不能无凭据找回。微信内置浏览器和系统浏览器存储不同，建议用常用系统浏览器并收藏。

## 实际架构

- GitHub 保存排除私密数据后的源码；Pages 保留静态展示页。
- Sites 提供页面与 /api/ 的同一 HTTPS 来源。公开星空首页无需 ChatGPT 登录；心网记录仍须各自身份授权。平台登录 Cookie/身份头不会转发给 Neon，只有心网自身 HttpOnly Cookie 会被转发。
- Neon 项目 xinwang 的 production 分支保存 PostgreSQL 数据；xinwang Function 用 Node.js 24 执行原有后端。数据库连接由 Neon 自动注入，使用直接连接以支持完整事务。Neon Function 不承载网站页面。
- XINWANG_SETUP_KEY、PUBLIC_ORIGIN、XINWANG_API_ORIGIN 仅通过运行环境设置，源码只保存变量名。本地 data/、真实 .env、恢复码、数据库、备份和部署凭证都不得提交。
- Render 因当前账户要求绑卡而停止使用；render.yaml、start:cloud 只保留为可选旧适配，不是当前正式服务。

没有绑定银行卡、升级付费套餐或购买主机。免费服务有配额和休眠限制；首次打开可能需要等待或刷新，不能承诺无限容量或永久无故障。不要外部定时保活或自动升级。

官方说明：[Neon Functions](https://neon.com/docs/compute/functions/overview)、[运行限制](https://neon.com/docs/compute/functions/reference/runtime-limits)、[环境变量](https://neon.com/docs/compute/functions/environment-variables)。

## 安全与维护

这是账号之间的服务器权限隔离，不是端到端加密。HTTPS、数据库 TLS 保护传输；记录正文在数据库中未作应用层加密，服务器和数据库维护者仍可能访问。双方定期“导出我的记录”，未加密的 JSON 各自保管。

正式接口严格校验 HTTPS 来源、Origin、CSRF、会话、作者和当前绑定。访问他人的私密编号返回 404，未登录请求记录返回 401。浏览器不保存密码或正文到 localStorage；服务出错不会假报保存成功或降级读取旧原型副本。

本机仍用 npm start / SQLite；云端依赖通过 npm ci 安装。server/neon-function.mjs 连接 Neon Web 请求与原有 Node API，hosting/neon/index.mjs 是部署入口。Sites 转发源码备份在 hosting/sites/。两部分分别打包，不能把整个项目和 node_modules 不经检查直接上传。

上线前的隔离测试覆盖真正 PostgreSQL、双账号、免密码邀请/恢复和手机尺寸。线上只做匿名可达性及权限拒绝检查，尚未声称两台真实手机实测。首个真实身份由用户自己设置；不在生产库预填测试账号或测试留言。
