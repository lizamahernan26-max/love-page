# 计时数字字体

首页计时及纪念日期使用 **LXGW WenKai Mono TC（霞鹜文楷等宽 TC）** 的数字与标点子集，只含空格、0—9、句点、冒号和间隔点；英文及中文正文未切换字体。

- 官方项目：https://github.com/lxgw/LxgwWenKaiTC
- 来源：Google Fonts 提供的文字子集，查询 `family=LXGW+WenKai+Mono+TC&text=0123456789.%3A%20%C2%B7`。
- 网页内置文件：`assets/fonts/lxgw-wenkai-mono-tc-numerals.woff2`，2,032 字节。
- 许可：SIL Open Font License 1.1，原文随字体保存在 `assets/fonts/OFL.txt`，构建时一并保留。

字体已保存在项目中，网页打开时只向本站请求，不依赖访问 Google Fonts 或手机已安装楷体。等宽数字配合固定时分秒容器、齐线数字和同一行高，防止秒数变化时左右跳动。
